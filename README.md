## Yellow Wallpaper Script

This project now includes an example script that cycles your Windows desktop background through 512 shades of yellow. The script requires [Node.js](https://nodejs.org/) with the `jimp` and `wallpaper` packages installed.

Run the script using:

```bash
node scripts/yellow_wallpaper.js
```

The script generates a solid color image for each tone and sets it as the wallpaper with a short delay, creating a smooth transition.
